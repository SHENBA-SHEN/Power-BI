POWER BI PROJECT-1 - HR DATA


Develop a Power BI project focused on HR data for a company facing challenges in comprehending their employees
data to extract valuable insights. Construct a comprehensive dashboard that includes the following components:


   SUMMARY PAGE:
1. Present a snapshot of key HR metrics.



   HEADCOUNT ANALYSIS:
1. Showcase Year-on-Year trends in Headcount and Attrition.
2. Illustrate Headcount breakdown by Business Unit.
3. Display Headcount distribution across various age groups.
4. Analyze Headcount based on gender.
5. Breakdown of Headcount by Job Title.
6. Show Headcount distribution across different departments.


SLICER FOR ENHANCED ANALYSIS:
Implement multiple slicers enabling dynamic filtering by :  
    1. Department
    2. Country
